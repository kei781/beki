# CV3 HR Workforce Management Platform 🏢

> **직원 출퇴근과 관련한 통합 인력관리 및 근태 자동화 플랫폼**
> 지문인식기 데이터를 기반으로 출퇴근 및 추가근무를 자동 산정하고, 복잡한 연차/보상휴가 부여 및 캘린더 연동을 자동화합니다.

<br>

## 📌 프로젝트 개요 (Overview)

### 🚨 문제 정의
- **수기 관리의 한계:** 지문인식기 엑셀 데이터를 수동 취합하며 발생하는 HR 부서의 리소스 낭비 및 휴먼 에러
- **복잡한 휴가 정책:** 입사일 기준(1년 차)과 회계연도 기준(2년 차 이상) 혼재, 추가근무 보상휴가(1.5배) 등 복잡한 계산 로직
- **정보의 파편화:** 팀원 부재 일정이 실시간으로 공유되지 않아 발생하는 커뮤니케이션 비용

### 💡 기대 효과
- **운영 효율화:** 근태 데이터 업로드 즉시 출퇴근/추가근무/보상휴가가 자동 계산되어 HR 리소스 80% 절감
- **투명성 확보:** 대시보드를 통한 실시간 개인 잔여 연차, 출퇴근 기록 조회
- **협업 강화:** Google Calendar 자동 연동으로 팀 내 부재 상태 실시간 공유
